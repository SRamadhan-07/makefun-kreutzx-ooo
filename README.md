A Python program — standard library only, no network — that writes one line to /output/entry.txt: an out-of-office message announcing the sender is away until Monday while their inbox is monitored by a goldfish with a law degree, so response times may improve. The line is 120 characters, inside the competition's gate of 1 to 140 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
